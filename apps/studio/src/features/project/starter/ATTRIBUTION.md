# Starting Demo Project

The three haptic patterns and durations come from Pulsar Studio's original Starting Demo Project: ExplosionAnimation (2333 ms), FanfareSound (5187 ms), and JustHaptics (4366 ms). Coordinates and values are unchanged. Studio's node IDs are omitted from the portable haptic files. The bundle adds Buzzzz editor metadata to preserve each canvas duration.

The attached animation and audio are unchanged copies of the matching files in the official Pulsar app's `PulsarAppBundle.pulsar`. Their SHA-256 hashes match the credits in Pulsar Studio's deployed media panel.
